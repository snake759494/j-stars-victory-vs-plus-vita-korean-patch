# 기술 설명

## CPK

게임 데이터는 `data/VITA/partition_op_{game,battle,progress,character}_vita.cpk` 4개입니다. CRI CPK이며 `@UTF` 표(TOC 등)는 XOR로 가려져 있습니다(키 0x655f에서 시작해 바이트마다 ×0x4115). 패치는 바꾼 파일을 CPK 끝에 덧붙이고 TOC 행의 오프셋·크기 바이트만 제자리에서 고칩니다(`tools/cpk.py`). 원본 데이터가 그대로 남으므로 xdelta가 작고 파일 크기 제한이 없습니다.

## `$CMP` 압축

빅엔디언 헤더(0x04 = 청크 크기+0x10, 0x10 = 풀린 크기, 0x1C = 0x000f0000) 뒤에 청크가 이어집니다.

- `$CL0`: LZ. 리터럴은 `b>>1`, 복사는 shift 6: 개수 `(b&63)>>1`, 거리 `((b>>6)<<8)|다음 바이트`
- `$CLH`: 허프만(`$CH0`, 4바이트 항목 code 19비트·len 5비트·sym)으로 감싼 `$CL0`
- `$CH0` 단독: 기호 1개 = 채우기

다시 넣을 때는 리터럴만 쓴 `$CL0`으로 만들며 게임이 그대로 받아들입니다(`tools/scmp.py`).

## KPTS 아카이브 (`*_m.pak`, `*_v.pak`)

0x30바이트 항목(오프셋, 크기, 0, 0, 이름 32바이트)과 0x40 정렬 데이터입니다(`tools/stpk.py`, `tools/pakedit.py`). 이름은 32바이트에서 잘려서 `.srd`가 `.s`로 끝나거나 `_m`/`_v` 표지가 잘리기도 합니다. `_m.pak`(정보)과 `_v.pak`(텍스처 데이터)의 짝은 이름을 정규화해 맞춥니다(`pakedit.mvkey`).

## 텍스트

`*_US_m.pak` 안의 UTF-16LE(BOM 포함) `.txt` 파일 하나가 문장 하나입니다. 같은 영어 문장이 여러 파일에 있으므로 영어 문장 → 한국어로 바꿉니다(고유 문장 17,534개, 파일 36,724개). `_NS` 등 다른 지역 pak은 쓰이지 않아 손대지 않았습니다. 스태프롤 파일은 제외합니다.

## 글꼴 `op_font_US_VITA`

`game/resident/game_resident_US_m.pak`의 `.stx`(SRD: `$TXR`/`$RSI`/`SpFt`)와 `_v.pak`의 `.srdv` 텍스처(DXT1, 2048×H, Vita 스위즐)입니다.

- `SpFt`: U+0020부터의 비트필드(0x1FE0바이트), 맨 앞에 0이 하나 있는 누적 색인표, 글리프 항목 8바이트(x 12비트|y 12비트, w, h, l, r, yoff). 헤더 0x28 = 글리프 표 다음 오프셋
- 한글 1,235자와 새 기호를 텍스처 아래쪽에 이어 그리고 비트필드·색인·글리프 표를 다시 만듭니다(`tools/fontbuild.py`).

## 그림 글자 (SRD 텍스처)

`$TXR` 형식은 0x11 DXT5, 0x0f DXT1(둘 다 스위즐 값과 관계없이 항상 Vita 스위즐), 0x05 선형 ARGB4444(u16, 위 4비트가 알파, 줄 간격 있음), 0x01 BGRA(선형일 수 있음)입니다. 2의 거듭제곱으로 채워져 있으며 데이터 위치는 `$RSI`에 있습니다(`tools/srd.py`, `tools/dxt.py`).

다시 그리는 방법(`tools/retext.py`):

- 원본 글자 영역을 찾아 지우고(인페인팅 또는 투명화), 원본 색·그라데이션·테두리·기울기를 재서 한글을 그립니다.
- 빛 번짐 층(`_ef*`)과 색 변형(`_bl`/`_rd` 등)은 주 층의 위치에 맞춰 같은 모양으로 만듭니다(`tools/layers.py`).
- 줄 높이 15px 이하는 갈무리 비트맵 글꼴로 선명하게 그립니다.
- 로딩 TIPS(1280×720)는 제목·본문을 자동으로 찾아 바꾸고(`tools/tips.py`), 스크린샷 속 빨간 띠·주황 글씨 설명은 위치·각도를 지정해 바꿉니다(`tools/tipcaps.py`).
- VS 화면 캐릭터 이름은 `progress/coomon_chara_name/US/`(원본 경로 철자 그대로)에, 배틀·선택 화면 이름은 캐릭터 CPK의 `battle_character_*`에 있습니다.

## 확인 방법

Vita3K(Qt 프런트엔드, Vulkan)를 백그라운드 창으로 띄워 키 입력을 보내고, Vita3K 자체 스크린샷 단축키로 화면을 받았습니다(`tools/emu.py`). 남은 영어는 텍스처 전체를 덤프해 목록과 대조하고 플레이하며 찾았습니다.
